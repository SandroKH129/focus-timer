# Focus Timer ⏱️

A simple study timer based on the Pomodoro technique, with a built-in task list.

## Features
- 25-minute focus timer and 5-minute break timer
- Animated progress ring (SVG)
- Start, pause and reset controls
- Task list: add, complete and delete tasks
- Tasks and daily round count saved with localStorage
- Dark mode (follows your device settings)
- Responsive layout for phones and desktops

## Built with
- HTML
- CSS
- JavaScript (no libraries or frameworks)

## What I learned
- How `setInterval` works for countdowns
- How to draw a progress ring with SVG
- How to save data in the browser with localStorage
- How to make a layout that works on mobile

## Run it locally
1. Download or clone this repository
2. Open `index.html` in your browser
